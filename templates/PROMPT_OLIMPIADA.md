## Тип задачи (ориентир — уточни по фото)

Симуляция доставки заказов курьерами. Типичные условия (проверь по заданию!):

- Расстояние: **манхэттенское** `|x1-x2| + |y1-y2|`
- Скорость: **1 единица координат в минуту**, целые числа
- У курьера есть **грузоподъёмность**
- У заказа есть **временное окно** `[time_start, time_end]`
- После рейса курьер **возвращается на базу**
- Вход: **CSV** с секциями `# Couriers` и `# Orders` (или другой формат — см. фото)
- Выход: **хронологический лог** + **сводный отчёт** + **ASCII timeline** по курьерам (или как в условии)

Если в задании другие правила — **следуй заданию**, а не этому списку.

## Требования к коду

1. **Один файл `main.py`** — dataclass, enum, функции, класс симулятора, `main()`.
2. Только **стандартная библиотека** Python.
3. CLI: `python main.py input.csv`
4. Обработка ошибок: файл не найден, битые строки CSV.
5. Код **читаемый**, с короткими комментариями только там, где логика неочевидна.
6. Алгоритм: **достаточно хороший для олимпиады за 4 часа** (не over-engineering):
   - планировщик: EDF (по дедлайну) + жадный выбор курьера с мин. временем прибытия;
   - симуляция: пошагово, 1 тик = 1 минута;
   - статусы: доставлен вовремя / с опозданием / не доставлен.
7. Выведи **полный код всех файлов** целиком, без `...` и пропусков.

## Формат вывода (если совпадает с типовым)

1. Строка: `Загружено: N курьеров, M заказов.`
2. **Хронологический лог** — события с меткой `[t=...]`
3. **Сводный отчёт** — таблица заказов + статистика (вовремя / опоздание / не доставлено)
4. **ASCII timeline** — полоска активности каждого курьера  
   Символы: `D`=вовремя, `L`=опоздание, `-`=в пути, `w`=ожидание окна, `r`=возврат, `.`=на базе

Если в условии другой вывод — сделай **как в условии**.
