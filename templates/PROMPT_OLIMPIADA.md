## Что нужно сделать

Реши задание **полностью** и выдай готовый проект для сдачи.

### Обязательные файлы (если условие не требует иного)

| Файл | Описание |
|------|----------|
| `main.py` | **Весь код в одном файле** |
| `README.md` | Документация на русском |
| Пример входных данных | Файл(ы) в формате из условия (`input.csv`, `input.txt` и т.д.) |

### Дополнительно — только если требует условие

Примеры: второй тестовый файл, файл с ожидаемым выводом, конфиг, несколько входных наборов и т.п.

## Требования к решению

1. **Один файл `main.py`** — весь исполняемый код в нём (если в условии не сказано иначе).
2. **Только стандартная библиотека Python 3.8+** — без pip-пакетов, если условие не разрешает иное.
3. **CLI** — команда запуска ровно такая, как указана в задании (если не указана — предложи логичную и опиши в README).
4. **Обработка ошибок** — некорректный ввод, отсутствующий файл, битые строки: понятное сообщение, без падения с traceback (если условие не требует иного).
5. Код **читаемый**: dataclass / enum / функции / классы — по смыслу задачи; комментарии только там, где логика неочевидна.
6. Алгоритм — **достаточный для олимпиады за ~4 часа**: рабочий, без over-engineering и лишних абстракций.
7. Выведи **полный код каждого файла целиком** — без `...`, без пропусков, без TODO и заглушек. Код должен **запускаться сразу**.

- [ ] Критерии оценивания (если видны) — на что обратить внимание

## Порядок работы

1. Прочитай все фото.
2. Составь краткую выжимку условия (вход → логика → выход).
3. Напиши `main.py`, пример входных данных, `README.md`.
4. Сверь результат с примерами из задания (если они есть).
5. Убедись, что пример входа покрывает разные случаи из условия (успех, ошибка, граничные ситуации — что применимо).
