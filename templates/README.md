## Формат входного файла

CSV с двумя секциями:

```
# Couriers
id, max_weight, start_x, start_y

# Orders
id, x, y, weight, time_start, time_end
```

| Поле | Описание |
|------|----------|
| `max_weight` | Грузоподъёмность курьера (кг) |
| `start_x, start_y` | Стартовая позиция курьера |
| `x, y` | Координаты точки доставки |
| `weight` | Вес заказа (кг) |
| `time_start` | Начало временного окна (мин) |
| `time_end` | Конец временного окна / дедлайн (мин) |

## Выход программы

1. **Хронологический лог** — события доставки `[t=...]`
2. **Сводный отчёт** — статус каждого заказа + статистика
3. **ASCII timeline** — активность курьеров по времени

## Алгоритм

### Планирование

<!-- Опиши свой алгоритм: EDF, жадный, ближайший сосед и т.д. -->

- Заказы сортируются по дедлайну (`time_end`)
- Для каждого выбирается курьер с минимальным временем прибытия
- Учитываются грузоподъёмность и временные окна

### Симуляция

- Скорость: 1 единица координат в минуту
- Расстояние: манхэттенское (`|Δx| + |Δy|`)
- После рейса курьер возвращается на базу

## Обработка ошибок

- Файл не найден → сообщение и выход
- Некорректная строка → предупреждение, строка пропускается
- Пустые секции → сообщение об ошибке
