# Симулятор доставки — Московские мастера

Консольная программа на Python для симуляции доставки заказов курьерами.

## Требования

- Python 3.8 и выше
- Только стандартная библиотека (сторонние пакеты не нужны)

## Использование

```
python main.py input.csv
```

## Формат входного файла

CSV-файл с двумя секциями. Строки, начинающиеся с `#`, задают секцию; пустые строки игнорируются.

```
# Couriers
id, max_weight, start_x, start_y

# Orders
id, x, y, weight, time_start, time_end
```

| Поле         | Тип  | Описание                                        |
|--------------|------|-------------------------------------------------|
| `id`         | str  | Идентификатор курьера / заказа                  |
| `max_weight` | int  | Максимальная суммарная грузоподъёмность (кг)    |
| `start_x/y`  | int  | Начальная позиция курьера                       |
| `x, y`       | int  | Координаты точки доставки                       |
| `weight`     | int  | Вес заказа (кг)                                 |
| `time_start` | int  | Начало временного окна (минуты от старта)       |
| `time_end`   | int  | Конец временного окна (дедлайн)                 |

### Пример файла

```csv
# Couriers
C1,30,0,0
C2,20,0,0

# Orders
O1,5,0,15,3,20
O2,0,8,12,5,25
O3,3,3,10,0,15
O4,9,9,5,15,40
O5,6,6,15,0,10
```

## Вывод программы

Программа последовательно выводит три секции:

1. **Хронологический лог** — каждое событие доставки с временной меткой `[t=...]`
2. **Сводный отчёт** — статус каждого заказа, время доставки, статистика
3. **ASCII временная шкала** — горизонтальная полоска активности каждого курьера

### Символы на шкале

| Символ | Значение                               |
|--------|----------------------------------------|
| `D`    | Доставлен вовремя                      |
| `L`    | Доставлен с опозданием                 |
| `-`    | Курьер в пути к точке доставки         |
| `w`    | Курьер ждёт начала временного окна     |
| `r`    | Курьер возвращается на базу            |
| `.`    | Курьер на базе (простой)               |

## Алгоритм

### Планировщик маршрутов (EDF)

Используется стратегия **Earliest Deadline First** (самый срочный — первым):

1. Заказы сортируются по дедлайну (`time_end`), затем по началу окна.
2. Для каждого заказа перебираются курьеры: выбирается тот, у которого **минимальное время прибытия**, при условии:
   - хватает свободной грузоподъёмности,
   - курьер успевает до конца окна (`arrival ≤ time_end`).
3. Заказы без подходящего курьера получают статус **FAILED**.

### Симуляция (пошаговая, 1 шаг = 1 минута)

- Скорость движения: **1 единица координат в минуту**.
- Расстояние: **Манхэттенское** (`|Δx| + |Δy|`).
- На каждом шаге каждый курьер либо движется к следующему заказу, либо ждёт начала временного окна, либо возвращается на базу.
- **Возврат на базу** происходит автоматически после выполнения всего маршрута.

### Статусы заказов

| Статус        | Условие                                                         |
|---------------|-----------------------------------------------------------------|
| `DELIVERED`   | Доставлен в интервале `[time_start, time_end]`                  |
| `LATE`        | Доставлен после `time_end` (курьер всё равно доехал)            |
| `FAILED`      | Ни один курьер не мог успеть в срок или нести такой вес         |

## Структура кода (`main.py`)

```
OrderStatus          — перечисление статусов заказа
Order                — dataclass заказа
Courier              — dataclass курьера (с изменяемым состоянием)
manhattan()          — расчёт манхэттенского расстояния
step_toward()        — один шаг по манхэттенскому пути
load_data()          — парсинг CSV с секциями
_estimated_arrival() — оценка времени прибытия с учётом очереди
plan_routes()        — EDF-планировщик назначений
DeliverySimulator    — пошаговая симуляция + три метода вывода
main()               — точка входа CLI
```
