# Pokemon Binder Pokedex

Статическое MVP-приложение для учёта карточек Pokemon TCG в биндерах.

## Что умеет

- искать покемона по английскому имени или номеру через локальный кеш, а при отсутствии кеша догружать из [PokeAPI](https://pokeapi.co/);
- принимать имя в любом регистре, например `pikachu`, `Pikachu` или `PIKACHU`;
- предлагать варианты имён покемонов во время ввода из локального индекса `data/pokemon-index.json` (официальный National Dex #1–#1025);
- показывать картинку, типы, рост, вес, опыт и способности;
- перед добавлением показывать, в какой биндер, лист, сторону и ячейку класть карту;
- рисовать схему стороны листа и подсвечивать нужную ячейку;
- размещать карту по номеру покемона, а не по порядку добавления;
- показывать позицию: биндер, лист, лицевая/задняя сторона, номер ячейки;
- открывать отдельную вкладку `Мой Pokedex` с сеткой официальных покемонов #1–#1025 (Bulbasaur → Pecharunt);
- подсвечивать собранных покемонов активными квадратами, а несобранных показывать серыми;
- показывать подробности покемона по клику на квадрат;
- настраивать количество биндеров, листов, сторон и ячеек на сторону;
- сохранять настройки в `localStorage` браузера;
- сохранять добавленных покемонов в SQLite-базу `data/pokedex.sqlite`.

## Запуск

Открой `index.html` в браузере.

Запусти backend-сервер из этой папки:

```powershell
py -3 server.py
```

Затем открой `http://127.0.0.1:5173`.

## Обновление индекса покемонов

Локальный список имён лежит в `data/pokemon-index.json` (только National Dex #1–#1025). Чтобы скачать свежий список из PokeAPI:

```powershell
py -3 scripts\download_pokemon_index.py
```

Локальные данные для карточки покемона лежат в `data/pokemon-details/<id>.json`. Чтобы заранее скачать/обновить данные всех 1025 официальных покемонов:

```powershell
py -3 scripts\download_pokemon_details.py
```
