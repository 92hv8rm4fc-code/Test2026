# FolioGrid — универсальный офлайн-биндер карточек

Отдельное iPhone-приложение, созданное на основе удачных UX-идей первого
биндера, но **без Pokémon и другой встроенной интеллектуальной собственности**.
Корневой Pokédex-проект не является частью FolioGrid и не изменяется этим
подпроектом.

## Возможности

- несколько независимых списков/коллекций;
- мастер импорта из вставленного текста или таблицы, CSV и XLSX;
- настраиваемый разделитель вставленного списка: авто, новая строка, пробел,
  табуляция или собственный символ/последовательность;
- выбор столбца с названием карточки;
- исходный, алфавитный или многоуровневый порядок по трём столбцам;
- последовательная нумерация или номера из файла;
- статусы «в коллекции» и `wishlist`;
- пользовательские фотографии карточек;
- поиск, фильтры и сортировка;
- расчёт места в физическом биндере;
- прогресс `собрано / всего`;
- локальное хранение в IndexedDB без аккаунта и сервера;
- полностью офлайн после установки.

## Быстрый запуск в браузере

```bash
cd universal-card-binder
npm install
npm run serve
```

Открой `http://127.0.0.1:5174`.

## Установка на iPhone через Xcode

На Mac:

```bash
cd universal-card-binder
npm install
npm run ios:open
```

В Xcode:

1. Target **App** → **Signing & Capabilities**.
2. Выбрать свой Team / Apple ID.
3. При необходимости заменить Bundle Identifier `app.foliogrid.binder`.
4. Подключить iPhone, выбрать его как destination.
5. Нажать **Run** ▶.

После Run приложение установлено на iPhone. С бесплатной Personal Team подпись
обычно нужно обновлять повторной установкой через Xcode примерно раз в 7 дней.

## Обновление iPhone-сборки

```bash
git pull
cd universal-card-binder
npm install
npm run ios:open
```

Затем снова Run в Xcode.

## Приватность и резервные копии

Списки и фотографии хранятся только локально на устройстве. Удаление приложения
удалит эти данные. Экспорт резервной копии указан в плане как следующий приоритет.
