# Лицензии и интеллектуальная собственность

## Собственные материалы

- Код приложения создан для FolioGrid.
- Иконка `assets/foliogrid-icon.png` создана специально для проекта как
  абстрактная композиция из карточек и сетки. Она не использует символы известных
  карточных франшиз.
- В приложении нет встроенных названий, изображений, логотипов и баз данных
  Pokémon, Magic: The Gathering, спортивных лиг или других брендов.

## Зависимости

| Пакет | Назначение | Лицензия |
|---|---|---|
| Capacitor Core / iOS / CLI | iOS-оболочка | MIT |
| read-excel-file | чтение пользовательских XLSX | MIT |
| esbuild | локальная сборка XLSX-модуля | MIT |
| http-server | локальная разработка | MIT |
| Playwright Core | автоматический smoke-тест интерфейса | Apache-2.0 |

Точные тексты лицензий устанавливаются npm в `node_modules/<package>/LICENSE`.
Перед публикацией нужно повторно проверить версии из `package-lock.json` командой
`npm license-checker` или эквивалентным аудитом.

## Пользовательский контент

FolioGrid — пустой инструмент. Пользователь самостоятельно добавляет названия и
фотографии. Это снижает риски распространения чужого контента разработчиком, но не
автоматически даёт пользователю права публиковать или распространять загруженные
материалы.

## Название

`FolioGrid` выбрано как нейтральное рабочее название. Перед App Store или
коммерческим запуском необходим поиск по товарным знакам и названиям приложений в
целевых странах. Этот документ не является юридической консультацией.
