# FolioGrid: план и карта проекта

## Цель

FolioGrid — полностью автономный универсальный каталог физических коллекционных
карточек. Приложение не содержит названий, изображений или данных конкретной
франшизы. Пользователь сам импортирует список и при желании добавляет собственные
фотографии.

## Принципы

1. Никаких встроенных каталогов или изображений сторонних брендов.
2. Все пользовательские данные остаются на устройстве.
3. Импорт не должен требовать сервера или интернета.
4. Каждая коллекция изолирована: свои поля, порядок и параметры биндера.
5. Исходный список не меняется после импорта; статус и фото редактируются отдельно.

## Реализованные этапы

- Мастер импорта: вставка текста/таблицы, CSV и XLSX.
- Выбор названия коллекции и столбца с названием карточки.
- Порядок: исходный, алфавитный или до трёх правил по столбцам.
- Нумерация: последовательная после сортировки или из выбранного столбца.
- Предпросмотр перед сохранением.
- Несколько независимых коллекций.
- Статусы «в коллекции» и «в wishlist».
- Собственные фотографии карточек.
- Поиск, фильтрация и сортировка.
- Расчёт места в физическом биндере.
- Копирование wishlist.
- Офлайн-хранилище IndexedDB.
- Capacitor/Xcode-проект для iPhone.

## Следующие разумные этапы

1. Экспорт и импорт резервной копии FolioGrid JSON.
2. Редактирование строк и пользовательских полей после импорта.
3. Массовое изменение статусов.
4. Несколько экземпляров одной карточки и состояние экземпляра.
5. Облачная синхронизация как отдельная добровольная функция.
6. Тесты импорта для сложных CSV/XLSX.
7. Проверка названия FolioGrid по реестрам товарных знаков перед публикацией.

## Где что находится

| Файл | Ответственность |
|---|---|
| `index.html` | Экраны, мастер импорта, модальные окна |
| `styles.css` | Адаптивный интерфейс и iPhone safe area |
| `app.js` | Импорт, сортировка, UI, логика биндера |
| `storage.js` | IndexedDB и операции с коллекциями/карточками |
| `scripts/prepare-www.sh` | Офлайн-сборка для Capacitor |
| `capacitor.config.json` | Настройки iOS-приложения |
| `docs/DATA_MODEL.md` | Формат данных |
| `docs/LICENSES.md` | Проверка зависимостей и ассетов |

## Правило для будущих изменений

Изменения универсального приложения делаются только внутри
`universal-card-binder/`. Корневой Pokémon-проект не используется и не меняется.
